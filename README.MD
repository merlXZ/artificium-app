# Artificium — AI Tools Dashboard 🚀

An interactive dashboard and user interface for an artificial intelligence platform. The project features a modern web interface with an emphasis on clean design, readability, and a strict responsive grid.

## 🎯 About The Project

Artificium is a frontend project demonstrating modern cross-browser layout skills. The primary goal was to create a complex yet intuitive dashboard interface (Creative Assets, Developer Tools, Content Creation, etc.) without overloading it with heavy frameworks. 

Built using a classic web technology stack (vanilla web layout), the project delivers maximum performance and instant page load times.

## 🛠 Technologies

* **HTML5:** Semantic markup and strict document structure.
* **SCSS (CSS3):** Custom properties (variables) for the color palette and design constants.
* **SVG:** Vector graphics for icons to keep the UI sharp across all screens (Retina-ready).
* **JS:** Pure Vanilla JavaScript.

## ✨ Key Features

* **Responsive Design:** The interface renders properly on wide desktop monitors as well as mobile devices. The card grid automatically calculates available space.
* **Component-Based Approach:** Despite the absence of JS frameworks, styles and markup are logically divided into independent blocks (sidebar, category cards, navigation).
* **Simple Authentication Flow:** A straightforward and clear registration and login system implemented without relying on third-party frameworks.
